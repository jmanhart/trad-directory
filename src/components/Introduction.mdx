# Trad Directory — Component Library

A living gallery of the UI that powers [Trad Directory](https://trad-directory.vercel.app),
a directory of traditional (American traditional / "trad") tattoo artists and shops.

Built with **React + TypeScript + Vite**, styled with CSS Modules on top of a
shared design-token layer (`src/styles/variables.css`).

## What's in here

- **Search** — the centralized `SearchBar` with grouped artist / shop / location suggestions.
- **Map** — the side panels that surface when you drill into a city, shop, or artist on the map.
- **Common** — small reusable primitives like `CountBadge` and `Pill`.
- **Brand** — the logotype and production wordmarks.

Stories use mock data only; nothing here talks to the live database.
